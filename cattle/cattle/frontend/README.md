# Smart Livestock Frontend

A React (Vite) single-page app that connects to the backend API at `http://localhost:4000/api` by default.

Run locally:

- npm install
- npm run dev

Pages:
- Dashboard (charts)
- Cows (list and add)
- Trade (record trades)
- Predict (submit metrics for disease prediction)
- Advisory (list and add advice)
- Grants (list and add grants)
