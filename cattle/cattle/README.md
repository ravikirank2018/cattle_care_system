# Smart Livestock Management

Monorepo with `backend/` (Express API) and `frontend/` (React + Vite) for a Smart Livestock Dashboard focusing on cow health monitoring, trade, disease prediction, advisory, and grants.

Quick start:

- Start backend: cd backend && npm install && npm run dev
- Start frontend: cd frontend && npm install && npm run dev

Docker compose:

- docker compose up --build
